artefactual.WEPR#

class artefactual.WEPR(estimator=None)[source]#

Bases: TokenProbaMixin, PretrainedMixin, SavePretrainedMixin, ClassifierMixin, BaseEstimator

Scores logprob arrays with a mean and a max per rank, the Weighted EPR.

Two features per rank let the calibration weight the informative ranks over the rest, so it reads strictly more of the distribution than EPR. Input and targets are as for EPR; the weights are fixed at the width they were trained at, which the pooling’s feature count then enforces.

Parameters:

estimator (estimator, default=None) – Final classifier with fit and predict_proba, never fitted in place: a clone is trained. None is the unregularised logistic regression. A FrozenEstimator holds pretrained weights, which fit keeps.

Variables:

  • fitted_pipeline (Pipeline) – The pipeline fit trained; absent on a detector that only carries frozen weights.

  • pipeline (Pipeline) – The pipeline that scores: the entropy step and the classifier. fitted_pipeline_ once fit ran, else rebuilt from a FrozenEstimator.

  • classes (ndarray of shape (2,)) – The class labels, sorted.

  • n_features_in (int) – Last dimension of the input fitted on.

Raises:

TypeError – From fit and predict*, if given completion responses instead of logprob arrays.

Examples

>>> detector = make_pipeline(LogProbParser(k=15), WEPR()).fit(
...     responses, y
... )

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → WEPR#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:

sample_weight (str, True, False, or None, default=sklearn.utils.metadata_routing.UNCHANGED) – Metadata routing for sample_weight parameter in score.

Returns:

self – The updated object.

Return type:

object
