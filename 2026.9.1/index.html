Artefactual#

Artefactual assigns a language model’s answer a probability of being a hallucination. It reads the answer that has already been generated, together with the token probabilities returned alongside it, and needs nothing else from the model.

pip install artefactual

from artefactual.scoring import BaseDetector

# response is what any OpenAI-compatible client returns with logprobs=True, top_logprobs=15
detector = WEPR.from_pretrained("artefactory/wepr-ministral")
detector.predict_proba(response)[:, 1]   # P(hallucination) per sequence
