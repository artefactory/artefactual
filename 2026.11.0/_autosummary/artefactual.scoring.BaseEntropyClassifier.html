artefactual.scoring.BaseEntropyClassifier#

class artefactual.scoring.BaseEntropyClassifier(k, estimator=None, *, transform_input=None, memory=None, verbose=False)[source]#

Bases: Pipeline, PretrainedMixin, SavePretrainedMixin

An entropy -> classifier pipeline returning P(hallucination) from logprobs.

A scikit-learn Pipeline, so predict, predict_proba, fit, get_params and clone behave as expected and the estimator composes into GridSearchCV and friends. It holds the logic every detector shares: the parameters, the target checks, the persistence and the per-token scores. Abstract in the pooling: EPRClassifier and WEPRClassifier are the classes to construct, and each fixes pooling and the coefficient width that pooling implies.

Class 1 is the hallucination class: predict_proba(…)[:, 1] is the score of interest, as long as the labels are 0/1. Column order follows classes_.

Input is the (n_sequences, n_tokens, width) logprob array LogProbParser emits, or a numeric 2-D (n_samples, width) table, whose rows are read as one-token sequences of per-rank logprobs. Ranks beyond k are dropped, which are the least likely candidates; a narrower input is used as it is and fits coefficients of that width. Targets are binary only.

fit leaves steps as the same list object it received, and get_params reports estimator=None while the final step is still the untouched default, so that clone rebuilds an equal estimator.

Parameters:

  • k (int) – Candidates per token. Written to every step before the classifier, so that set_params(k=), which is how GridSearchCV sweeps it, reaches them all.

  • estimator (estimator, default=None) – Final estimator. Unfitted by default: the unregularised logistic regression the published detectors were fit with, so coefficients fitted here are comparable to the shipped ones. C=np.inf rather than penalty=None: the latter is deprecated in scikit-learn 1.8 and removed in 1.10, and the two produce identical coefficients.

  • transform_input (list of str, default=None) – Passed to Pipeline.

  • memory (str or object with the joblib.Memory interface, default=None) – Passed to Pipeline.

  • verbose (bool, default=False) – Passed to Pipeline.

Variables:

  • classes (ndarray of shape (2,)) – The class labels, sorted; column i of predict_proba is class classes_[i]. Available once fitted.

  • n_features_in (int) – Width of the table, or last dimension of the 3-D array, fitted on. Reading it before fitting raises AttributeError.

  • feature_names_in (ndarray of str) – Column names of a table fitted on, when they are all strings.

  • named_steps (Bunch) – The steps by name: “entropy” and “classifier”.

  • steps (list of (str, estimator)) – The same steps, in order.

  • estimator (estimator) – The final step. Read from, and writing it replaces, steps[-1]. Writing None restores the default.

Raises:

TypeError – If constructed directly rather than through EPRClassifier or WEPRClassifier.

Notes

estimator is a property reading the final step, so it would always report the default classifier instance the constructor built, and clone would then differ from the constructor argument None (sklearn’s clone checks identity). While the final step is still a default LogisticRegression, None is reported, and the rebuilt estimator builds the same default. A step that was replaced or had a parameter changed through set_params is reported as itself. With estimator reported as None, its estimator__* sub-parameters are omitted, as their classifier__* twins already carry them.

property k: int#

Candidates per token, read from the first step.

Written to every step before the classifier that takes a k, so that set_params(k=) reaches the steps that act on it instead of setting an attribute nothing consults. set_params(entropy__k=) changes one step only, and then that step alone reads fewer ranks than the others hand it, so sweep k, not the step parameter.

Raises:

ValueError – If the first step was replaced by one that has no k, such as “passthrough”.

Per-token hallucination probabilities, for locating where a response drifts.

Runs the transformer steps in token mode (transform_tokens, falling back to transform), then scores only the non-padded token rows and scatters the results back, so padded positions stay NaN rather than being scored as real tokens.

Pipeline.set_params, where estimator__<p> sets <p> on the final step.

get_params reports estimator=None while the final step is the untouched default, and the base class would route estimator__<p> to that None. The final step is the estimator, so the key is addressed to it directly. A call that also replaces estimator keeps its keys as given, so they reach the replacement.

set_score_request(*, sample_weight: bool | None | str = '$UNCHANGED$') → BaseEntropyClassifier#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.

Parameters:

sample_weight (str, True, False, or None, default=sklearn.utils.metadata_routing.UNCHANGED) – Metadata routing for sample_weight parameter in score.

Returns:

self – The updated object.

Return type:

object
