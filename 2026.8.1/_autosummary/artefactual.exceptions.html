artefactual.exceptions#

Warnings and errors raised across the package.

Both hierarchies have a base class so callers can catch or filter the whole family: ArtefactualWarning for recoverable conditions, ArtefactualError for failures.

Exceptions

ArtefactualError

Base for all artefactual errors, so callers can catch the family.

ArtefactualWarning

Base for all artefactual warnings (subclass of UserWarning → shown by default, filterable).

EmptySequenceWarning

A sequence had no tokens; scored at the classifier baseline.

UncalibratedModelError([message])

Raised when a detector is built with neither pretrained weights nor trainable=True.

Bases: ArtefactualError

Raised when a detector is built with neither pretrained weights nor trainable=True.

A detector has no default calibration: the coefficients are model-specific, so an unfitted classifier would return probabilities backed by nothing. The two ways to resolve it are naming a calibration or asking for an unfitted pipeline to fit.
